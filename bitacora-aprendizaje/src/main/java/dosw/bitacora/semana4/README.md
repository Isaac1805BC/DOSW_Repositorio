## Semana 4: Análisis de Requerimientos

### 1. Diagrama de Contexto de UBER 
Representa el sistema de software que se está construyendo y cómo interactúa con las personas y otros sistemas.
* **Sistema Central:** Sistema Core de Uber.
* **Actores:** Pasajero y Conductor.
* **Sistemas Externos:** Pasarela de Pagos y Sistema de Mapas.

### 2. Ejercicio: Formulario de Inscripción de la Escuela
* **Nombre:** Inscripción de Aspirante.
* **Descripción:** Como aspirante, quiero diligenciar un formulario web con mis datos para solicitar mi admisión a la institución.
* **Cómo se ejecutará:** Vía interfaz web.
* **Actor Principal:** Aspirante.
* **Datos Entrada/Salida:** Datos personales e Email de confirmación.
* **Flujo Básico:** El usuario ingresa, llena los datos, valida y el sistema guarda el registro confirmando el éxito.
* **Flujo Alterno (Excepciones):** Alerta de datos incompletos en lenguaje claro o validación de usuario previamente registrado.
* **Reglas de Negocio:** El botón de validación debe ser morado, respetando el sistema de diseño.
