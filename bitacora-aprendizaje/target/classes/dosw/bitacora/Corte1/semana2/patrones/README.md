## Semana 2: 

* **Ejercicio 1 - Patrón Creacional (Factory Method):** Implementación de una fábrica de logística donde se separó la creación de camiones y barcos de la lógica central usando interfaces.
* **Ejercicio 2 - Patrón Estructural (Adapter):** Adaptador de corriente para unificar voltajes de 220V europeos y 110V americanos sin alterar la clase original.
* **Ejercicio 3 - Patrón de Comportamiento (Memento):** Editor de texto con funcionalidad de deshacer (Ctrl+Z) aislando el historial (Caretaker) del estado original (Originator).
* **Ejercicio 4 - Principios SOLID (Calculadora simple):** Refactorización de una calculadora aislando la suma, resta y multiplicación en clases propias para cumplir con Responsabilidad Única (SRP) y Abierto/Cerrado (OCP).
